Put your research facilities video file in this folder and name it exactly:

    research-facilities.mp4

The Research Facilities page (research_facilities.html) already points to
"./videos/research-facilities.mp4", so as long as the file uses that exact
name and sits in this folder, it will show up automatically - you can swap
the video file for a new one later and just keep the same filename, no HTML
edits needed.

Recommended format: .mp4 (H.264) for the widest browser support.
If you'd rather use a different filename or format (e.g. .webm), update the
<source> tags inside research_facilities.html to match.
